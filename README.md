# H5 data (simulated)

The 20 simulated genome sets of hypothesis H5 (docs/PREREGISTRATION.md, Amendments 4 and 5 on the main branches), made on the development laptop with scripts/simulate_hgt.sh. Each file is sequences.fasta compressed with gzip -n -9. The SHA-256 of every uncompressed file equals the value in data/manifests/simulated/hgt.tsv; scripts/baselines.sh checks it again before use.

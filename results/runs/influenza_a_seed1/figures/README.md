# figures

## Purpose
Figures of the run, drawn from its reports (plan 4.7, 4.8). Not part of the root fingerprint; `qmaws figures` draws them again.

## Contents
| Item | Description |
|---|---|
| `convergence.pdf` | nRF of each provisional tree to the final tree (PDF) |
| `convergence.png` | nRF of each provisional tree to the final tree (PNG, 300 dots per inch) |
| `convergence.svg` | nRF of each provisional tree to the final tree (SVG) |
| `groups.tsv` | Group of every taxon in the group bands, with the source in the first line |
| `halo_tree.pdf` | Quartet Halo Tree (PDF) |
| `halo_tree.png` | Quartet Halo Tree (PNG, 300 dots per inch) |
| `halo_tree.svg` | Quartet Halo Tree (SVG): branch colour and width by support, halo ring, group bands, title block |
| `halo_tree_growth.gif` | Animation of the provisional trees, ending with the final tree |
| `interactive_tree.html` | Interactive tree: one self-contained file; zoom, pan, taxon search, tooltips, circular or rectangular layout |
| `live/` | Latest provisional Halo Tree, drawn while the quartets were weighed |
| `rectangular_tree.pdf` | Rectangular tree (PDF) |
| `rectangular_tree.png` | Rectangular tree (PNG, 300 dots per inch) |
| `rectangular_tree.svg` | Rectangular tree (SVG) with support values, halo squares and groups |

## Relationships
Written by `crates/qmaws-engine` (analysis run and `qmaws verify`).

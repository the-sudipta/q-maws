# trees

## Purpose
Final trees of the run.

## Contents
| Item | Description |
|---|---|
| `bootstrap_trees.nwk` | The tree of every S2 bootstrap replicate, one per line in replicate order |
| `bootstrap_trees.nwk.sha256` | SHA-256 of `bootstrap_trees.nwk`, written after it (validity check) |
| `tree_s1.nwk` | The tree with S1 as internal labels |
| `tree_s1.nwk.sha256` | SHA-256 of `tree_s1.nwk`, written after it (validity check) |
| `tree_s2.nwk` | The tree with S2 (bootstrap split frequencies) as internal labels |
| `tree_s2.nwk.sha256` | SHA-256 of `tree_s2.nwk`, written after it (validity check) |

## Relationships
Written by `crates/qmaws-engine` (analysis run and `qmaws verify`).

# Peafowl on hgt_h010_r2

Outputs of `scripts/baselines.sh peafowl hgt_h010_r2`; the status and versions are in `provenance.txt`.

| Item | Content |
|---|---|
| `comparison.tsv` | nRF, nQD and MSD of the tree against the reference or species tree (`qmaws tree-compare`) |
| `comparison_error.txt` | Messages of `qmaws tree-compare` (empty when it worked) |
| `provenance.txt` | Status, tool version and settings, runner and date of the run |
| `stderr.txt` | The program's messages (standard error) |
| `stdout.txt` | The program's output (standard output) |
| `tree.nwk` | The tree made by the tool (Newick) |

# inputs

## Purpose
Input data of the positive and negative controls.

## Contents
| Item | Description |
|---|---|
| `fish_shuffled/` | Fish mtDNA, each sequence shuffled on its own (negative control) |
| `simulated/` | Sequences simulated along a random tree (positive control) |

## Relationships
Written by the hidden command `qmaws controls` (`crates/qmaws-cli/src/controls_cmd.rs`).

## Notes
Recreated by the command with the same seed.

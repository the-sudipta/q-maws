# H5 dataset hgt_h000_r3

Simulated genome set with transfer fraction h = 0, replicate 3 (30 taxa; data on the branch `h5-data`, species tree `data/manifests/simulated/trees/hgt_h000_r3.nwk`).

| Item | Content |
|---|---|
| `ml_maws/` | ML-MAWS run (`--strand --iqtree`, IQ-TREE 2.4.0) |
| `qmaws/` | Q-MAWS run (primary configuration, seed 1, S1), with its own README; the large `work/` folder is not committed |
| `v2/` | Q-MAWS v2: the W1 tree of the same run (`qmaws variant --weights w1`) |

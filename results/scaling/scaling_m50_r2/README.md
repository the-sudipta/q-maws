# Scaling dataset scaling_m50_r2

Simulated genomes, 50 taxa, replicate 2 (1,000,000 letters each; manifest `data/manifests/simulated/scaling.tsv`). Times are in `../times.tsv`.

| Item | Content |
|---|---|
| `ml_maws/` | ML-MAWS run (`--strand --iqtree`, IQ-TREE 2.4.0) |
| `qmaws/` | Q-MAWS run (primary configuration, seed 1, S1), with its own README; the large `work/` folder is not committed |

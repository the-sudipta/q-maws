# figures

## Purpose
The result charts of the thesis and paper (`paper/`), drawn from the committed result tables by `scripts/paper_figures.py`.

## Contents
| Item | Description |
|---|---|
| `paper/` | Final figures for the publication ([README](paper/README.md)) |

## Relationships
Run figures are produced by `crates/qmaws-viz` and stay in each run folder in `results/`; the charts in `paper/` come from the result tables.

## Notes
Per-run figures live in each run folder under `results/runs/`; only figures chosen for publication are copied here.

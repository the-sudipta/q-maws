# docs

## Purpose
Project documentation for readers, users and reviewers: the method, design decisions, external tools and dependencies, open issues, user and teaching guides, and one report per milestone.

## Contents
| Item | Description |
|---|---|
| `DEPENDENCIES.md` | Every Rust crate used, with license and reason |
| `DESIGN.md` | Software design decisions and their justification |
| `EXTERNAL_TOOLS.md` | External tools, services and repositories, with what was verified about each |
| `METHOD.md` | Mathematical specification of the method for readers |
| `milestones/` | One report per completed milestone ([README](milestones/README.md)) |
| `OPEN_ISSUES.md` | Problems, ambiguities and discrepancies found, with options |
| `PREREGISTRATION.md` | Hypotheses, tests and success criteria, fixed before any experiment |
| `TEACHING.md` | How to use `qmaws teach` in a classroom |
| `USER_GUIDE.md` | Menus, commands and screenshots |

## Relationships
Describes the code in `crates/`, the data in `data/`, and the results in `results/`. Milestone reports cite measurements from logged runs.

## Notes
Plain engineering tone. Every number comes from a logged run or a cited source. Documents marked "to be written" are filled in by the milestone named in them.

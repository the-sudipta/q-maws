# M7: Amalgamation

Status: **complete, awaiting the owner's approval**.

## What was built

- **License check:** wQFM (Mahbub et al., *Bioinformatics* 2021), official repository github.com/Mahim1997/wQFM-2020, commit `7bfdf8e` (v1.4), is under the Apache License 2.0. Reuse is permitted; the notice is in `THIRD_PARTY_NOTICES`.
- **`wQFM-rs`** (`qmaws-core::amalgamate`): divide-and-conquer bipartitioning of weighted quartets as in the paper (sections 2.5 and 2.6), with the v1.4 code's choices where the paper leaves details open (initial bipartition, FM tie-breaking, dummy taxa, merging of equal deferred quartets). Details are in `docs/DESIGN.md`.
- **Exhaustive oracle** for m ≤ 10 (all unrooted binary trees by stepwise addition) and the weighted quartet consistency score.
- **Analysis stage `amalgamate`:** W2c weights (W2b without resamples) of every quartet in rank order, output `report/tree.nwk` and `work/amalgamation.json`; resumable and part of the root fingerprint.
- **Jar comparison (development only):** hidden commands `qmaws wqfm-export` and `qmaws wqfm-compare`, `scripts/wqfm_check.sh`, and the GitHub Actions workflow `wqfm.yml`. Java is never needed by Q-MAWS itself.

## Findings

- **`wQFM-rs` matches the jar exactly** on every comparison input, including the noisy and real ones, where only a score ratio of 0.999 was required.
- **wQFM is a heuristic:** on small noisy inputs its score can be up to 7% below the exhaustive optimum (worst 0.929). The jar behaves the same way, since the topologies are identical.
- **The strand filter hurts on Fish mtDNA** with this first tree (nRF 0.500 against 0.136 without it). ML-MAWS showed the same direction (0.409 against 0.182). This is exploratory; the evaluation is planned for later milestones.
- Amalgamation is not the bottleneck: at m = 116 it is 222 s, against hours for W2c weighting on the larger datasets (M5).

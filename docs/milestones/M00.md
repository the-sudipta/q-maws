# M0: Foundation and pre-registration

Status: **in progress**. The skeleton, guard and launchers are complete, and the pre-registration is committed (decision D1, 2026-10-02). `CITATION.cff` waits for decision D11. This report is updated when the milestone is closed.

## What was built

- **Repository skeleton** with a README in every folder (sections Purpose, Contents, Relationships, Notes), root README draft, `.gitignore`, `.gitattributes`, `CHANGELOG.md`, `CONTRIBUTING.md`, `THIRD_PARTY_NOTICES`, and the owner-supplied `LICENSE` committed unchanged.
- **Cargo workspace** with seven crates (`qmaws-core`, `qmaws-engine`, `qmaws-data`, `qmaws-viz`, `qmaws-tui`, `qmaws-gui`, `qmaws-cli`), toolchain pinned to Rust 1.98.1, edition 2021. No external crates. The `qmaws` binary supports `--help` and `--version` only.
- **Pre-commit guard** (`scripts/pre-commit`), installed as both the `pre-commit` and `commit-msg` hooks by `scripts/install-hooks.sh` or `scripts\install-hooks.bat`, with a self-test (`scripts/test-guard.sh`).
- **README coverage check** (`scripts/check-readmes.sh`).
- **Launch scripts** `run.bat` and `run.sh`.
- **Pre-registration** (`docs/PREREGISTRATION.md`) with the primary configuration confirmed by the owner (decision D1, 2026-10-02): `M_full`, W2c with 100 resamples, W2-sym (W2-emp as ablation), `wQFM-rs`, S1 (S2 only if feasible, decision D7). Committed before any experiment.

## Known limitations

- No analysis functionality exists yet; `qmaws menu`, which the launch scripts start when given no arguments, reports that it is not available.
- The guard does not support paths containing a newline character.
- The launch scripts and installers were tested on Windows only (Git Bash for `run.sh`); macOS and Linux are tested by CI from milestone M1.
- `LICENSE` Section 12 contains a placeholder contact address (`docs/OPEN_ISSUES.md`, OI-1).

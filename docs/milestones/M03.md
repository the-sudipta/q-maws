# M3: MAW extraction, strand filter, length selection, matrices

Status: **complete, awaiting the owner's approval**. Not tagged yet; the tag will be `v0.3-m03-matrices`.

## What was built

- **MAW extraction** (`qmaws-core::maw`): online suffix automaton; enumeration of minimal absent words with lengths in [l_min, l_max] by ML-MAWS's method (depth-first walk over factors, suffix-link test); words stored 2 bits per letter (`u64` up to 32 letters, `u128` up to 64); brute-force oracle.
- **Strand filter**: MAWs of the sequence intersected with those of its reverse complement, as in ML-MAWS.
- **Length selection** (`qmaws-core::matrix`): ML-MAWS's adaptive range table, entropy per length with `libm::log2`, the top 3 lengths with at least 5 variable columns (relaxed if fewer qualify), ties to the shorter length.
- **Matrices**: `M_full` (all MAWs of the selected lengths, lexicographic order, bitset row per taxon) and `M_ml` (constant columns removed, at most 50,000 columns by min(n_j, m − n_j), ties by column order); PHYLIP export in ML-MAWS's layout.
- **Pipeline** (`qmaws-engine::matrix_pipeline`): parallel extraction within a memory limit (70% of available memory), memory estimate of `M_full` printed and checked before it is allocated (decision D3 if it does not fit), release of sequences and unselected lengths as soon as possible.
- **Command** `qmaws matrix --dataset <id> | --input <folder> --output <folder> [--no-strand] [--lengths a,b,c]`.
- **Equivalence check** with ML-MAWS on GitHub Actions (`.github/workflows/equivalence.yml`, `scripts/equivalence.sh`): ML-MAWS is built on the Linux runner at commit `0c38db1`, outside the repository, as the owner chose (no compiler is installed on the laptop).

## Findings

- **OI-9:** the length range in ML-MAWS's code is a fixed table on the average length, not the paper's formula with log2 and L_cap; the code is reproduced and gives the paper's ranges.
- **OI-10:** ML-MAWS has no defined tie rule for equal entropies; Q-MAWS takes the shorter length.
- **OI-11:** ML-MAWS source headers say "License: MIT"; the repository license is Apache-2.0.
- ML-MAWS has no Makefile (its README says `make`), and does not compile with current GCC without `<cstdint>`.

## Known limitations

- MAWs longer than 64 letters are not supported (ranges reach at most 18).
- On computers with little free memory, extraction runs one taxon at a time.
- Matrices are built by `qmaws matrix`; they become stages of a resumable run (`maw_extract`, `strand_filter`, `length_select`, `matrix_build`) together with quartet counting in M4.
- Peak memory was measured only for E. coli, from outside the program; the program's own memory measurement comes with the run statistics.

# M2: Input and data acquisition

Status: **complete, awaiting the owner's approval**. Not tagged yet; the tag will be `v0.2-m02-data`.

## What was built

- **Input reading and cleaning** (`qmaws-core::input`): FASTA or raw sequence text, `.txt`, `.fa`, `.fasta`, `.fna`, `.fas`, each optionally `.gz`; the cleaning rules in order (headers, whitespace and digits removed; upper case; U to T; only A, C, G, T kept, removals counted per symbol); every validation finding with its choices; Newick-safe names; renaming of duplicates. One taxon per file in folders, one per record in a single multi-FASTA file (D13); records named by their whole header (owner decision on OI-7).
- **Newick** parsing, writing and name matching (`qmaws-core::newick`).
- **Benchmark registry** (`data/manifests/benchmarks.toml`, compiled in): 15 downloads, 19 datasets.
  - 9 AFproject datasets (Fish mtDNA, E. coli/Shigella, E. coli/Shigella HGT, Yersinia HGT, simulated HGT 0, 250, 500, 750, 1000), each with a reference tree.
  - 5 NCBI datasets (coronavirus, ebolavirus, influenza A segment 6, mammal mtDNA, rhinovirus) built from the accession lists of Li, He, He and Yau (2017), with pinned record versions (D5, D10).
  - 5 ML-MAWS data files, reference only (`*_mlmaws`).
- **Downloads** with `.part` files, HTTP range resume, 5 attempts with back-off, MD5 and SHA-256 verification, delete-and-retry-once on mismatch; atomic, safe zip extraction; the download log.
- **NCBI fetching** with E-utilities: batched, rate-limited, with tool and email; every record and version checked.
- **Reference trees** for the AFproject datasets, with name tables, in `data/references/`.
- **Commands** `qmaws datasets`, `qmaws download --dataset <id or all>`, `qmaws inspect --input <folder or file> | --dataset <id> [--reference <tree>] [--compare-with <id>]`.
- **ML-MAWS** cloned outside the repository (`../_external/ML-MAWS`, commit `0c38db1`, Apache-2.0) and inspected (`Data/`, `README.md`, `FastaReader.cpp`, `main.cpp`, benchmark scripts).

## Findings

- **Influenza A** is the neuraminidase segment (about 1.4 kb), as stated by its source publication; the 13 kb average in ML-MAWS Table 2 does not describe these data (OI-6).
- **Simulated HGT archive** has one folder per HGT level, not five multi-genome files (OI-5).
- **Table S4 of Li et al. (2017)** lists Ebolavirus genome lengths that decrease by exactly 1 per row; they are not used.
- The NCBI documentation page answered with a reCAPTCHA check; it was not bypassed, and the usage rules were read on two other official NCBI pages.
- **Bug found and fixed during the real NCBI fetch:** syncing a file opened read-only fails on Windows ("Access is denied"); the provenance table is now synced through a writable handle.

## Known limitations

- Input warnings are listed by `qmaws inspect` with their choices; the interactive questions come with the menus in a later milestone.
- The progress bars of downloads were not inspected on an interactive terminal; plain output was checked.
- No whole-genome influenza dataset was built (it can be added as a labelled "reconstructed" dataset if wanted).
- The remaining-time estimate issue of M1 (calibration on this laptop) is unchanged.

# M14: Release readiness

Status: **complete; v1.0.0 published on 2026-10-16** (branch `m14`). Plan: Part 11, M14.

## What was built

- **Window** (`crates/qmaws-gui/`): a redesign with a sidebar (Home, New run, Resume, Verify, Results library, About), the new-run steps with Browse buttons, the live Halo Tree in the style of the final figure, the live worksheet of the quartet being weighed, a Details panel (stage, speed on this computer, time left, expected finish in local time, every stage, the full log), zoom controls, light and dark themes, the Q-MAWS icon, and opening directly on a double-click.
- **Batch progress view** (plan 5.5.1): during a queue, the whole batch in the terminal, in the window (Queue card) and as the offline page `batch_status.html`, with a dataset × seed grid; plus the M11 progress board (`qmaws monitor`).
- **Run lock** (`work/run.lock`): one process at a time works on a run; the terminal, the menu and the window refuse a run in use and skip it in `resume --all`.
- **Full CI** (`.github/workflows/ci.yml`): formatting, lints and tests on Windows, macOS and Linux, golden test G12 (the Fish mtDNA root fingerprint equal on all three), dependency checks with `cargo deny`.
- **Release workflow** (`.github/workflows/release.yml`): on a tag `v<version>`, builds bundles for Windows (x64), macOS (Apple silicon and Intel) and Linux (x64), each with the program, `run.bat` or `run.sh`, `README.md`, `LICENSE`, `THIRD_PARTY_NOTICES` and `CITATION.cff`, publishes them with `SHA256SUMS.txt` and the notes of that version from `CHANGELOG.md`.
- **Documentation:** `docs/USER_GUIDE.md` with screenshots of the window and the batch view, `docs/TEACHING.md`, the final README (status, results of the pre-registered evaluation, how to reproduce them), `CITATION.cff` and `.zenodo.json` at version 1.0.0, and the CHANGELOG entry for 1.0.0.
- **Windows background speed:** the program asks Windows not to run it in efficiency mode when it runs hidden (about ten times faster in hidden queues; results unchanged).

## Acceptance criteria

| Criterion | Result |

The download test of the published bundles is done right after v1.0.0 is published |
| CI green on all platforms | Done on the pushed commits of `m14` |
| A queue of at least 3 runs shows the batch progress view in the window, the terminal and `batch_status.html`, with screenshots in `docs/USER_GUIDE.md` | Done (screenshots in `docs/images/`) |

## How it was verified

- On the release branch after merging the final results from `main`: formatting and lints clean, and all 355 tests pass in release mode.
- The version change to 1.0.0 does not change any result: the root fingerprint is computed from the settings and the content of each stage, not from the program version (builds of different commits gave the same roots throughout M11 to M13).

# M12: Calibration, sensitivity and seed variability

Status: **complete and approved by the owner** (branch `m11-complete`). Design: `docs/PREREGISTRATION.md`, Amendment 3. Every number comes from a file named next to it.

## What was built

- **Sensitivity tools** (commit 7b3f26c): `qmaws run --top-lengths K` (number of MAW lengths kept by the entropy selection) and `--matrix ml` (count the quartets on `M_ml`); the hidden `qmaws variant` (the tree of a finished run with W1, W2a, W2b or W2c weights from its stored quartet results), `qmaws calibration` (reliability table and ECE) and `qmaws tree-compare`.
- **H4** (`results/h4/`): ML-MAWS (commit 0c38db1, IQ-TREE 2.4.0, `--strand --iqtree`) run on the five simulated HGT datasets on GitHub's Linux runners; calibration of Q-MAWS S1 and S2 and of ML-MAWS UFBoot against the true tree.
- **Sensitivity** (`results/sensitivity/`): one factor at a time from the primary configuration on Fish mtDNA, E. coli/Shigella, simulated HGT 0 and simulated HGT 500. Weights W1, W2a, W2b from the seed-1 runs (`weights.tsv`); 24 runs for K = 1, 2, 4, strand filter off, `M_ml` and W2-emp (`settings.tsv`), each verified with `qmaws verify --quick` (PASS).
- **Seed variability**: from the five seeds of every dataset in M11 (`results/summary/qmaws.tsv`).

## Results

### H4: calibration (pre-registered)

150 internal edges (30 in each simulated HGT dataset), ECE with 10 equal-width bins (`results/h4/README.md`):

| Support | ECE |
|---|---|
| Q-MAWS S1 (primary, tested) | 0.200240 |
| ML-MAWS UFBoot on its reported tree (comparison) | 0.200200 |
| Q-MAWS S2 (secondary) | 0.086067 |
| ML-MAWS UFBoot on the consensus tree (descriptive) | 0.192467 |

**H4 is not supported:** the criterion ECE(S1) ≤ ECE(UFBoot) fails by 0.00004; the two are practically equal. In plain words: S1 ranks splits well but is not a probability. It is too low on true splits and its values below 0.5 are mostly false splits. S2, not the tested quantity, has less than half the calibration error of either.

### Sensitivity (exploratory)

nRF / nQD against the reference tree, seed 1 (`weights.tsv`, `settings.tsv`):

| Setting | Fish mtDNA | E. coli/Shigella | Sim. HGT 0 | Sim. HGT 500 |
|---|---|---|---|---|
| Primary (W2c, K = 3, strand on, `M_full`, W2-sym) | 0.455 / 0.371 | 0.654 / 0.416 | 0.533 / 0.503 | 0.533 / 0.439 |
| W1 weights | 0.364 / 0.143 | 0.385 / 0.218 | 0.367 / 0.322 | 0.333 / 0.319 |
| W2a weights | 0.682 / 0.494 | 0.731 / 0.366 | 0.700 / 0.447 | 0.700 / 0.443 |
| W2b weights | 0.636 / 0.231 | 0.577 / 0.428 | 0.533 / 0.330 | 0.500 / 0.405 |
| K = 1 | 0.636 / 0.350 | 0.654 / 0.420 | 0.433 / 0.421 | 0.533 / 0.429 |
| K = 2 | 0.545 / 0.323 | 0.654 / 0.424 | 0.533 / 0.472 | 0.533 / 0.491 |
| K = 4 | 0.455 / 0.278 | 0.654 / 0.416 | 0.533 / 0.547 | 0.500 / 0.495 |
| Strand filter off | 0.227 / 0.041 | 0.692 / 0.443 | 0.467 / 0.400 | 0.467 / 0.476 |
| `M_ml` | 0.455 / 0.371 | 0.538 / 0.264 | 0.467 / 0.267 | 0.533 / 0.430 |
| W2-emp | 0.409 / 0.213 | 0.385 / 0.180 | 0.467 / 0.328 | 0.367 / 0.338 |

In plain words:
- **W1 weights** gave a lower nRF and a lower nQD than the primary configuration on all four datasets, and the lowest nRF of every setting on the three datasets other than Fish mtDNA (tied with W2-emp on E. coli/Shigella). This finding led to Q-MAWS v2 (W1), which was pre-registered before testing and is tested in H5 on newly simulated data.
- **W2-emp** gave a lower nRF and nQD than the primary configuration on all four datasets. This is noted as a candidate only. Under Amendment 3 it would need its own amendment and a test on new simulated data before any claim; it is not tested here.
- **W2a** gave a higher nRF than the primary configuration on all four datasets (its nQD was lower on two). W2b, K, the strand filter and `M_ml` changed the results in different directions on different datasets.
- On Fish mtDNA, `M_ml` gave exactly the primary result, and turning off the strand filter gave the largest gain on any dataset (nRF 0.227). The effect of the strand filter is not consistent across the four datasets.

### Seed variability (primary configuration, 5 seeds)

From `results/summary/qmaws.tsv`: the sample SD of nRF over the five seeds is 0 for five of the nine reference datasets and at most 0.021 (E. coli/Shigella); the SD of nQD is at most 0.066 (simulated HGT 1000). The seed changes the processing order and the W2c resamples; the trees it gives differ little.

## How it was verified

- All 24 sensitivity runs passed `qmaws verify --quick`; their root fingerprints and build (`git_commit` ef7b226) are in each run's `audit/`.
- The M12 binary was checked against the first M12 binary: same options and the same root fingerprints (Yersinia HGT seed 3, `8502148d...`; Fish mtDNA with `--top-lengths 2`, `ed7eb5b5...`).

## How the runs were made

The M12 queue started on its own when M11 finished (2026-10-13 18:00 UTC). Its first binary (commit b8782e2) had been rebuilt from the wrong commit and lacked `--top-lengths` and `--matrix`, so 11 runs failed at once and one stopped at the automatic memory limit. The queue was stopped, the outputs of that first attempt were moved to `D:\_external\m12_first_attempt` (not used), and M12 restarted at 18:17 UTC with the build of commit ef7b226 (7b3f26c plus the call that keeps Windows from throttling the hidden queue) and `--memory-limit 2`. All 24 runs then finished. Details: `docs/milestones/M11.md`, "Build changes in detail".

## Known limitations

- The sensitivity analysis is one factor at a time on four datasets with seed 1 only (Amendment 3); interactions between settings are not studied, and no variant result is a tested claim.
- H4 uses the five simulated HGT datasets (150 edges); with ECE values this close, a different set of edges could reverse the order.
- Amendment 4 says W1 had a lower nQD than the primary configuration on three of the four datasets; `weights.tsv` shows a lower nQD on all four (for example Fish mtDNA 0.143 against 0.371). The pre-registration is left as written; this report gives the values of the table.
- ML-MAWS for H4 ran on GitHub's runners, not on the development laptop; support values do not depend on the computer, only on versions, settings and seed, which are recorded.

# M4: Quartet pattern counting and teaching mode

Status: **complete, approved by the owner on 2026-10-02**, tagged `v0.4-m04-counting` (on commit `69c2992`).

## What was built

- **Quartet ranks** (`qmaws-core::quartet`): rank C(a,1) + C(b,2) + C(c,3) + C(d,4) and unranking.
- **Processing order**: a keyed 4-round Feistel network with cycle-walking, a bijection of [0, Q) with O(1) memory, seeded by the run's seed.
- **Counting kernel**: co-occurrence tables for single taxa, pairs and triples; one 4-way AND-popcount per quartet; the 16 pattern counts by inclusion–exclusion (superset Möbius transform); run-time choice of the x86-64 `popcnt` instruction or portable `count_ones`.
- **Analysis runs** (`qmaws-engine::analysis`, command `qmaws run`): resumable stages `ingest`, `maw_extract` (checkpoint per taxon), `length_select`, `matrix_build`, `quartet_count` (chunked in the seeded order; chunks up to 3 s and 64 MB) and `finalize` (root fingerprint), with binary formats for MAW lists, `M_full` and count chunks (`store.rs`).
- **Teaching worksheet** (`qmaws-core::teach`, command `qmaws teach --example | --input <folder>`), with the golden file `tests/golden/worksheet_example.txt` and `docs/TEACHING.md`.
- **Newick splits** and normalised Robinson–Foulds distance.

## Findings

- **OI-12:** the golden worksheet's wording differs from the teaching material (numbered steps, `x` and `/`, every average written out, a fixed order of the four model terms); all values are identical. Approved by the owner on 2026-10-02.
- Counting is limited by memory traffic for wide matrices (153,122 quartets per second at 200,000 columns and 116 taxa against 1,642,567 at 10,000 columns).

## Known limitations

- Weighting, amalgamation, support, evaluation and figures are not yet stages of the analysis run.
- Count chunks need 72 bytes per quartet on disk (about 516 MB for 116 taxa); the disk-space check before a run comes with the run planning of later milestones.
- AVX2 and the optional triple cache were not added (the triple cache does not fit the permuted order).

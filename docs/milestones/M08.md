# M8: Support, audit, verification, controls

Status: **complete, awaiting the owner's approval**.

## What was built

- **S1 support and halo values** (`qmaws-core::support`, stage `support`): S1 for every internal edge and a halo value for every taxon, on the same weights as the tree. Outputs: `trees/tree_s1.nwk` (S1 as labels), `report/support.tsv`, `report/halo.tsv`.
- **S2 bootstrap support** (decision D7; stage `bootstrap`): 100 column-bootstrap replicates by default (`--bootstrap B`, 0 skips it), Poisson(1) column weights, weighted pattern counts, W2b weights inside, wQFM-rs; resumable per replicate. S2 of an edge is the fraction of replicate trees that contain its split. Outputs: `trees/tree_s2.nwk`, `trees/bootstrap_trees.nwk`, `report/bootstrap.tsv`. S1 stays the primary support.
- **Audit files** (`finalize`): `results.json` (trees, S1, S2, halo values), `quartet_decisions.bin.zst` (winning topology and 16-bit weight per quartet, zstd), `sample_worksheets.txt` (50 quartets drawn with a seed, each recomputed and checked against the stored weights), `environment.json` (version, git commit, device, settings, seeds), and `stages.json` with each stage's content hash, start and end time, and summary numbers (plan 4.6.2). The quartet worksheet (`qmaws-core::worksheet`) writes out every step from the co-occurrence counts to the W2c weights.
- **`qmaws verify`** (`qmaws-engine::verify`): input check, quick check (20 chunks per chunked stage and 3 bootstrap replicates, printed seed), full recomputation of the root, and single quartet with its worksheet. Without the `work/` folder the full matrix is rebuilt from the inputs, so `run.json`, `audit/` and the raw data are enough. Report in `report/verify_<time>.txt`.
- **Determinism contract** documented (`docs/DESIGN.md`). The root fingerprint (format v2) no longer depends on where the data are kept.
- **W2c star-fit rule** (OI-14, option b): a W2c resample whose three fits all have the internal branch at the lower bound counts as a three-way tie. Recorded as Amendment 1 of the pre-registration; H3 (M6) was run again.
- **S2 cost measurement** (hidden command `s2-cost`), measured before D7.
- **Controls** (hidden command `controls`, `qmaws-core::control`): sequences simulated along a random tree (positive), Fish mtDNA with each sequence shuffled (negative), and Fish mtDNA as a reference point; results committed in `results/controls/`.
- **G11**: a Fish mtDNA run killed 10 times and resumed (ignored test in `crates/qmaws-cli/tests/kill_resume.rs`).
- Run folders get README files written by the engine, and `.gitattributes` keeps run folders byte-exact in git, so their hash checks also hold after a Windows checkout.
- Documentation: README sections "Terminal mode" and "Verifying a run", `qmaws verify` and `--bootstrap` in `docs/USER_GUIDE.md`.

## D9

The decisions file has a fixed size before compression: 16 bytes of header and 3 bytes per quartet (`store::decisions_to_bytes`). For m = 116 (rhinovirus, the largest benchmark), 7,160,245 quartets give 16 + 3 × 7,160,245 = 21,480,751 bytes before compression, below the 25 MB threshold of plan 4.6.2, and zstd adds only a few hundred bytes even to data it cannot compress. D9 therefore does not arise. The measured compressed sizes are 10,066 bytes for Fish mtDNA (12,650 quartets) and 1,585 bytes for the simulated control (1,820 quartets). The compressed size at m = 116 will be measured when all datasets are run (M11). The 116-taxon run started for this measurement was stopped on the owner's instruction on 2026-10-03 after 306 of 5,577 weighting chunks.

## Findings

- **W2c on star-like quartets (OI-14), resolved.** For most quartets the two-state model fitted to MAW columns puts the internal branch at its lower bound in all three topologies (9,024 of 12,650 Fish quartets). Their log-likelihoods differed by about 10⁻⁵, so W2c gave near-certain weights to quartets without signal. With the owner's option (b) these resamples are ties: the negative control now has the no-signal support, the Fish tree is closer to the reference (nRF 0.455 against 0.500), and the simulated tree is recovered less well (0.308 against 0.154). The small likelihood differences carried some signal that the rule gives up.
- **S2 is low on Fish mtDNA** (mean 0.279) while S1 is 0.577: under column resampling with W2b, many splits of the tree are not stable.
- **The quartet decisions file** cannot re-run the amalgamation exactly, because the amalgamation uses all three weights (OI-13, resolved by option (a): the description was corrected). The full verification re-runs it from the data.
- **The root fingerprint depended on the data location**; fixed in M8 (format v2). Roots of runs made before this change differ from those made after it, as do roots made before the W2c rule and the S2 stage.

## Known limitations

- Quick verification recomputes 3 bootstrap replicates, not 20, because each replicate weighs every quartet once.
- G11's kills all fell in the weighting stage; resuming inside the bootstrap stage is tested with synthetic data only.
- `results.json` has an empty `metrics` block: nRF exists, nQD and MSD (plan 2.10) are not implemented yet.
- `docs/METHOD.md` (the mathematical description for readers) is still a placeholder, as since M3.
- `environment.json` records the commit of the build; a build from modified files is not marked as such.
- The interactive menu and its verify flow (plan 5.6) come with M9.

# standalone

## Purpose
Ready-to-run Q-MAWS v1.0.0 for Windows, macOS and Linux, so that it can be used without building it. Written by the release workflow; the same bundles are attached to the GitHub release.

## Contents
| Item | Description |
|---|---|
| `Q-MAWS-1.0.0-linux-x64/` | Q-MAWS v1.0.0 for linux-x64; see its README.md |
| `Q-MAWS-1.0.0-macos-arm64/` | Q-MAWS v1.0.0 for macos-arm64; see its README.md |
| `Q-MAWS-1.0.0-macos-x64/` | Q-MAWS v1.0.0 for macos-x64; see its README.md |
| `Q-MAWS-1.0.0-windows-x64/` | Q-MAWS v1.0.0 for windows-x64; see its README.md |

## Relationships
Made by `.github/workflows/release.yml` from the release tag.

## Notes
Replaced at every release. On Windows double-click `Q-MAWS.exe`, on macOS `Q-MAWS.app`, on Linux `Q-MAWS`; `run.bat` or `run.sh` start the terminal mode.

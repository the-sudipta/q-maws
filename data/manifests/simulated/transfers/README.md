# transfers

## Purpose
The horizontal transfers of every simulated HGT dataset of H5 (docs/PREREGISTRATION.md, Amendment 4): for each transferred gene, the leaves moved by the subtree prune-and-regraft and the leaves below the edge they were attached to.

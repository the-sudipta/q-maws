# data

## Purpose
Everything needed to obtain the input data reproducibly: dataset registries, accession lists, download logs, simulation recipes, and reference trees. Sequences themselves are downloaded or generated by the program and never committed.

## Contents
| Item | Description |
|---|---|
| `manifests/` | Dataset registries, accession lists, download log, simulation recipes ([README](manifests/README.md)) |
| `references/` | Reference trees with their sources ([README](references/README.md)) |

## Relationships
Read and written by `crates/qmaws-data`. Downloaded and generated sequences go to `data/raw/`, which is ignored by git and created on first download.

## Notes
`data/raw/` holds downloads: archives in `data/raw/_archives/`, extracted archives and single files in `data/raw/<download id>/` (see `manifests/benchmarks.toml`), and from M13 simulated sequences in `data/raw/simulated/`. It is created by `qmaws download`, listed in `.gitignore`, and blocked by the pre-commit guard.
